Help & transparency

Short, clear, and useful.

Why it runs automatically on eBay pages
HaggleOS uses a content_scripts rule that injects content.js on matching eBay pages. That injection creates the bottom-left button. Analysis runs when you click Analyze Deal.
What data is used
HaggleOS extracts listing details (e.g., title, price, images, fees/returns if available) from the current listing page, then sends the extracted payload to your backend for analysis.
Troubleshooting
  • No button? Make sure the URL contains /itm/, then refresh.
  • Panel shows API error? Backend may be down or blocked by network.
  • Nothing saves to history? Check extension storage permission and reload extension.
