## 💡 The Problem
We all love a bargain on eBay or Facebook Marketplace, but finding one is hard work. You have to:
1.  **Check prices** across the web to ensure you aren't being ripped off.
2.  **Inspect photos** pixel-by-pixel to find hidden damage.
3.  **Negotiate** with sellers, which is awkward, time-consuming, and emotionally draining.

## 🦅 The Solution: Kestral
**Kestral** is a multi-agent AI system that lives in your browser. It doesn't just watch listings; it **thinks, analyzes, and negotiates** for you.

Using a hybrid **Kestra + Vercel** architecture, Kestral deploys a team of 3 specialized AI agents to every product you view:
1.  **🕵️ Agent A (The Inspector):** Uses Vision AI to spot scratches, dents, and rust in listing photos.
2.  **📉 Agent B (The Analyst):** Scrapes real-time market data (Google Shopping) to find the *true* value.
3.  **🤝 Agent C (The Negotiator):** Drafts a perfect, psychology-backed offer based on the defects and market data.
